# How to use the `.hackathon/` working files

The **agent creates these in your actual app project** after you give an idea. They are not prefilled because the project idea is not known at install time.

- `.hackathon/BRIEF.md`: purpose, assumptions, user journey, acceptance criteria, out-of-scope.
- `.hackathon/TASKS.md`: P0/P1/P2 tasks with progress and tested evidence.
- `.hackathon/STATUS.md`: stage, working functionality, blockers, next immediate action.
- `.hackathon/QA.md`: actual command outputs and browser/manual check statuses.
- `.hackathon/DEMO.md`: startup, demo seed, click script, 60-second pitch, limitations.

Do not commit sensitive access tokens or private user information to these files.
