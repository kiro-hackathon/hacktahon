# Example ideas (not required to use the kit)

- "Build a web app that turns pasted messy lecture notes into spaced-repetition flashcards, supports local study sessions, and tracks progress without an account."
- "Make an interactive recycling sorter game for kids with 30-second rounds and accessible feedback."
- "Create a crowdsourced campus accessibility map where people can report ramps and obstacles. For the hackathon use clearly marked local sample data."
- "Build a shared grocery budget board for roommates that splits shared expenses, works offline, and has export-to-CSV."

A good hackathon idea fits this template:

`For [specific user], make [one important task] easier by [novel interaction]. Show it working with [sample input → visible outcome].`

One sentence is enough. Don't over-prompt; the agent is instructed to make practical decisions.
