# One-shot startup prompt

Copy everything in the code block below and replace `<PASTE IDEA HERE>` with your idea.

```text
You are my autonomous coding teammate for a THREE-HOUR AI VIBE CODING HACKATHON.

IDEA:
<PASTE IDEA HERE>

Read AGENTS.md, START_HERE.md, and the hackathon-director SKILL.md in this repository.
Follow the built-in sprint runbook and invoke relevant specialized skills as you work.

Decide the smallest valuable MVP without asking me minor preference questions.
Do lightweight research only if needed, timebox it strictly, then IMPLEMENT.
Use the existing stack if present. For a new project use the fastest appropriate
browser-first stack. Build one memorable working vertical slice, polished and responsive.
Use real functionality wherever feasible, and label any mock/sample mode clearly.
Start the app, test the primary workflow, fix failures, and prepare a reliable demo.
Preserve existing files. Do not expose secrets, claim tests you didn't run, or add
unnecessary dependencies. Freeze features before the QA phase.

Create brief status/QA/demo records under .hackathon/.
Work autonomously until the demo is runnable and the completion contract is met,
or until permissions, missing credentials or tool limits genuinely block further work.
Give me only concise milestone updates and a final tested run/demo checklist.

START NOW. Do not stop after writing a plan.
```
